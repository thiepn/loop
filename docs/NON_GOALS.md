# Loop — V1 Non-Goals

## Why this exists
The previous concept expanded from a small spatial audio experiment into a large modular DAW/acoustics platform. V1 must not repeat that pattern.

A feature being technically interesting is not enough reason to add it.

## Loop is not a DAW
Do not add V1 features whose main purpose is to imitate:
- Ableton Live;
- FL Studio;
- Logic;
- Bitwig;
- Pro Tools;
- professional clip/track arrangement workflows.

Specifically excluded:
- full linear arrangement timeline;
- large multitrack mixer;
- professional channel strips;
- mastering suite;
- complex automation editor;
- comping;
- detailed audio waveform editing;
- piano-roll-first workflow.

## Loop is not an acoustic engineering simulator
Excluded:
- user-drawn architectural wall simulation;
- physical material absorption configuration;
- Keller GTD diffraction controls;
- image-source room simulation;
- FDTD wave simulation;
- physically calibrated room modeling;
- architectural analysis metrics.

Musical spatial effects are allowed. Physical simulation is not a product requirement.

## Loop is not a modular-synth emulator
Excluded as primary UI:
- CV terminology;
- arbitrary patch matrices;
- complex signal graphs;
- exposed LFO/envelope routing;
- unlimited feedback routing;
- oscillator-by-oscillator synthesis programming.

Simple Links are allowed when expressed as understandable musical relationships.

## Loop is not a professional hardware workstation
Excluded:
- MPE workflows;
- advanced MIDI mapping;
- MIDI clock configuration;
- external control-surface setup;
- hardware-specific device profiles.

Basic future MIDI support may be reconsidered after V1 if it improves play without complicating the core product.

## Loop is not a native desktop app in V1
Excluded:
- Electron/Tauri requirement;
- VST/AU/CLAP plugin builds;
- native installers;
- filesystem-heavy project architecture.

The canonical V1 is the GitHub Pages web app/PWA.

## Loop is not a social platform in V1
Excluded:
- accounts;
- profiles;
- followers;
- public feeds;
- comments;
- cloud project library;
- real-time multiplayer;
- WebRTC jam rooms;
- server database.

## Loop is not an AI music generator
Magic may intelligently vary user-created material, but V1 does not aim to:
- generate complete songs from prompts;
- replace user interaction with one-click composition;
- require cloud inference;
- expose chatbot-driven composition as the main workflow.

The user should remain the person playing with the World.

## Loop is not unlimited
Do not support arbitrary numbers of:
- Sound Orbs;
- expensive effects;
- fields;
- Links;
- Snapshots;
- simultaneous granular processes.

Use tested caps that protect responsiveness.

## No feature because “it would be cool technically”
Features must pass the product decision test:
- immediate musical value;
- visual clarity;
- understandable interaction;
- playful expression;
- bounded complexity.

If a proposal mainly increases technical sophistication, defer it.

## Deferred ideas
Potential post-V1 experiments, not commitments:
- richer toy library;
- more World packs;
- deeper procedural/generative behavior;
- lightweight sharing;
- simple collaborative play;
- selected MIDI support;
- richer recording formats;
- optional creator tools.

These must be reconsidered against real V1 usage rather than automatically scheduled.

## Scope enforcement rule
When a future phase proposes functionality that conflicts with this document, this document wins unless the product contract is deliberately revised first.
